    第①层 agent 标记「有问题」的条目落这里，人裁决改法（改标题 / 补绑定 / supersede）。

    第 3 层

    落域确认 → 人唯一必须停顿的一秒（归档时点）

    归档收口最后一问：这批 FR 落这个域对吗？每变更一次 yes/no——专治 R17/R23 两轮实证的伪域病。选错域的代价是未来注入找错页，所以值得人工 1 秒。

    FR-03零业务判定红线（provisional 纯透传）
    FR-04pytest 五组全绿
    FR-05详情页观测事件折叠区（warning 展开+角标+琥珀高亮）
