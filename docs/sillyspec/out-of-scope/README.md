# out-of-scope（已拒绝概念沉淀位）

本目录登记**被拒绝的概念/提案**：每个被拒概念一个文件，附原始编号（issue/变更/会话出处）与拒绝理由。重复提案出现时直接引用对应文件回应，无须重新论证。

## 写法约定

- 文件名：`<概念 kebab-case>.md`（如 `mattpocock-skills-full-adoption.md`）
- 每份文件必含：概念一句话描述、拒绝理由（与内核机制的冲突点）、原始出处（变更名/issue 编号/日期）、复潮条件（什么前提下可以重新评估——无复潮可能的写「无」）
- 拒绝理由**引用源**（ROADMAP/knowledge/decisions），不双写正文——源更新时此目录不漂移

## 登记条件

- 用户明确否决的方向，或与仓库内核规约（如开放世界规约 00、双写漂移禁令）冲突的提案
- 曾被提出且论证后放弃的方案（防止后续会话不知情重新提出）
