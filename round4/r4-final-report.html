2我们的亮点

1 vs 0

全场唯一硬缺陷，出现在对方侧

对方把第三键写错（autoCompactPreCompute）：27/27 测试全绿 → 干净归档 → 错键进规格库 → 预计算开关生产 no-op。我们的 agent 联网核验官方文档后落码，多花 2.5 分钟拦下静默缺陷。

同一个错误

两边 agent 都猜了错键名——差别只在验证步

深读记录实证：我们的 agent 最初猜的也是那个错名，但先搜官方文档、拿到真名才写码。错误生成是确定性的，拦截是结构性的——这是流程属性，不是运气。

写码之前

独立设计审查拦下架构级错误（B1）

初版设计与 registry 源码契约矛盾，审查员独立核对源码后首轮打回、强制改设计。零代码浪费。对方流程无任何独立审查环节。

4 道防线

缺陷类覆盖：结构化 vs 全靠自觉

域事实核验 · 设计-源码一致性 · 声明-实测对账 · 资产正典校验，四类各有机制；对方四类全押 agent 自觉。历史数据：测试门两个月 12 次真拦「声称完成但测试挂」。

可检索资产

做完即沉淀

4 条决策 + 7 条 FR 索引 + ROADMAP + 模块文档 + 归档 15 件——下次变更直接复用。对方的规格库同样留资产，但本轮把错键典藏成了「正典」。

真并发

机制不是纸面

Wave 内 4 个子代理同窗并行（时间戳实证）；审查请求钳 3/3 阶段达标（11/6/6 ≤ 12/10/15）；进度库 / 边界审计 / 防作弊全程有效，双方 agent 零违反。

测试逻辑对比：两边测试都是 agent 写的，差在依据链与强制面 🅰 测试＝契约的执行形态：requirements 的 GWT 场景直接翻译成断言（如「230000 成功标准场景」用例）· 任务卡写死 verify 命令 · 存量测试当契约（改契约必须显式）；五层执行：子代理自跑 → 主代理复跑 → QA 独立复跑全量 → verify 门禁机器实测 → 相邻面回归。
🅱 测试＝agent 自觉：specs 与测试无强制映射（validate 只查格式），写多少凭理解、跑不跑无人拦——全绿可能是自指测试（断言自己写的实现，错键照样 27/27）。
诚实边界：测试防「实现与声明不符」，不防「声明与事实不符」——若我们写错键名，13 个用例同样全绿。拦错键的是联网核验不是测试：测试管一致性，核验管事实性。

4目前的差距（不回避）

1.3× / 2×

墙钟落后（小 / 大任务）

28 vs 21.5min；156 vs 80min。模型算力同量级，差距全部在非模型时间——门禁 + 编排等待，见下节拆解。

43% / 68%

子代理扇出的成本倍增

19 个子代理各自重建上下文，吃掉 42.3M tokens（43%）+ 522 请求（68%）。但这笔钱同时是上下文保险：每个子代理新鲜窗口（峰值 219K、用完即释），实现体量不进主会话——对方单会话上下文线性涨，爆了靠 auto-compact 硬扛（压缩丢细节）。
诚实注：我们的主会话峰值 377K 反高于对方 317K——编排侧自己也会胖，超大任务需派发瘦身。

~60%

大任务时间在等待

子代理执行 / 门禁运行 / 审查回收占六成墙钟，主代理生成不足三分之一。慢＝编排深度，但对外表现就是慢。

40% 假拦

门禁噪声真实存在（历史）

两个月 106 次门禁失败中：真拦 12、超时 36、环境 6。治理方向已定：按触碰模块收敛范围（文件级会漏真拦，有实证）+ 超时帽。

差距定性：等待与假拦是优化项；审查与扇出是防线的价格——砍掉它＝砍掉第 2 节的亮点。当前策略：保防线，砍等待。
扇出优化路线（砍冗余读取，不砍隔离与独立审查） ① 读取范围约束——allowed_paths 兼作读范围 + symbol-impact 符号锚点注入（直打 task-08 型 8.6M over-reading）
② 调研消化物共享——探索摘要落盘，实现子代理读两页 digest 替代重读源码（调研段 9.4M → ~5M）
③ batch 激进化——R4-S-F 实证 5 任务 2 batch 仅 6M：文件正交即并批，摊平 design/plan 重复重建
④ 派发材料包扩展——复用审查侧 assembleStageReviewMaterials 有界组装基建
⑤ 子代理模型分级——实现跑便宜档、审查保持旗舰（砍账单不砍 token）
预期 ①+②+③ 把子代理段 42M → 20-25M，大任务 99M → ~78M（差距 1.9×→~1.5×）；剩余差额＝上下文保险 + 独立审查的价格。

6一句话总结与选型

🅰 sillyspec ＝ 机器侧验证声称完成必须过实测对账；四类缺陷有结构化防线。代价：等待与仪式。
🅱 OpenSpec ＝ 模型侧自觉快、轻、零等待；防线全靠 agent 自觉——格式校验不校验事实。
  • 小任务 → sillyspec quick：28min、token 持平略优、一次过 + 资产落盘
  • 大任务 → 按缺陷成本选：生产平台（错一次贵）选全流程；原型快跑选轻流程
  • 互相借鉴：轻流程补「外部契约事实来源强制」；重流程做门禁模块粒度收敛

口径：sillyspec 墙钟为稳态（门禁单轮），OpenSpec 实测；tokens/请求均实测硬账 · n=1 对撞，墙钟按量级解读 · 底稿 sillyspec 仓 round4/
