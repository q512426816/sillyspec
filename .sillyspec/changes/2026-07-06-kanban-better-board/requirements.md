# 需求文档：Dashboard Kanban 看板视图

> 变更：`2026-07-06-kanban-better-board`

## FR-001: 看板 Tab 切换

看板视图通过 dashboard 的 Tab 栏切换访问，与现有"流水线""文档"Tab 并列。

- **验收标准**：Tab 栏显示 3 个选项 [流水线] [看板] [文档]，点击"看板"切换到看板视图
- **优先级**：P0
- **关联**：D-001@v1

## FR-002: 8 列阶段布局

看板按 8 个阶段分列：scan（代码扫描）/ brainstorm（需求探索）/ plan（实现计划）/ execute（波次执行）/ verify（验证确认）/ archive（归档变更）/ quick（快速任务）/ explore（自由探索）。

- **验收标准**：
  - 8 列水平排列，可横向滚动
  - 每列底部显示"暂无变更"空状态
  - 列标题显示阶段名和卡片数量
- **优先级**：P0

## FR-003: 变更卡片渲染

每张变更卡片展示：变更名称（2 行截断）、当前步骤描述、最后活跃时间、进度条（0-100%）。卡片左侧有阶段色条。

- **验收标准**：
  - 卡片显示变更名、步骤、时间、进度条
  - 进度条颜色：0%=灰 / >0%=黄 / 100%=绿
  - 左侧色条按阶段着色
- **优先级**：P0
- **关联**：D-002@v1

## FR-004: 卡片详情侧栏

点击变更卡片，右侧滑出详情面板，展示阶段标识、变更目录名、步骤描述、最后活跃时间、任务清单。

- **验收标准**：
  - 点击卡片 → 右侧滑出详情面板
  - 面板显示变更名称、阶段 badge、变更目录名、当前步骤、活跃时间
  - 面板显示该变更下的任务列表（含完成状态）
  - 点击面板外或关闭按钮 → 面板收起
- **优先级**：P1
- **关联**：D-004@v1

## FR-005: 后端数据端点

新增 `GET /api/changes/kanban` 端点，返回所有变更按阶段分组的数据。

- **验收标准**：
  - 请求 `/api/changes/kanban` 返回 `{ columns: [...] }` JSON
  - 过滤 `archive/` 子目录
  - 对每个变更返回 name / change / currentStage / step / lastActive / progress
  - 异常时返回空列数组 + HTTP 500
- **优先级**：P0
- **关联**：D-003@v1

## FR-006: 实时更新

看板数据在 WebSocket 推送变更后自动刷新。

- **验收标准**：
  - 收到 WebSocket `project:update` 消息后，看板重新加载数据
  - 加载中显示 loading 状态
  - 500ms 去抖，避免高频刷新
- **优先级**：P2
- **关联**：R-03
