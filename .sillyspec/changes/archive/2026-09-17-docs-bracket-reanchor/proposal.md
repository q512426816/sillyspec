# 提案：docs 引用锚方括号路径支持 + 陈旧基线自动重锚

## 背景与问题

用户 2026-09-17 工具使用小结负面两条（正面项棘轮拦截/`--against HEAD` 隔离不属修复面）：

1. **引用正则不支持方括号路径**：`REF_RE`（src/docs-check.js:125）文件段字符类只认圆括号段（路由组 `(dashboard)`，2026-09-08-docs-fix-capability D-006 展开），不含方括号段——Next.js 动态路由 `app/post/[id]/page.tsx`、`app/chat/[cid]/page.tsx` 全仓库写不了精确引用，只能靠 `...` 模糊逃逸（FR-1.2 skippedFuzzy，跳过校验）。方括号路径与圆括号路由组是同类框架适配缺口（工具↔Next.js），`SYMBOL_REF_RE`（src/docs-check.js:174）同款文件段同缺。
2. **陈旧基线提示反复出现但从不自动重锚**：docs gate 陈旧分支（src/docs-gate.js:194-199，坑 docs-gate-stale-baseline ql-20260915-004）已实测 origin/main 确认「本次不劣于远端」才放行，但只打印「建议 --init-baseline 重锚」——基线文件不落盘，下次跑 gate 再超基线、再付一次远端实测成本（临时 worktree + 全量 docs check）、再打一遍提示。用户实证：基线 404 < 远端 414 的提示反复出现。用户建议方向：提供 `--init-baseline` 的便捷触发；痛点本质 = 已验证事实不落盘。

## 方案对比

### 问题①（方括号路径语法）

| 方案 | 核心思路 | 优势 | 劣势 |
| --- | --- | --- | --- |
| A（选定） | 文件段展开循环里加方括号段形态：`(?:\([c]+\)|\[[c]+\])`（c=既有字符类），与圆括号段并列，`REF_RE`/`SYMBOL_REF_RE` 同步 | 与路由组同权同形（单一语法模型）；每次迭代仍必含完整括号段→划分唯一→线性（D-006@v1 约束保持）；markdown 链接 `[t](foo.js:12)` 在 `[t]` 后遇 `(` 无法接扩展名回落 `foo.js:12`（与圆括号回落同机理零回归） | 既有文档中散文形如 `arr[0].js:12` 新进入校验面（同圆括号扩展当年接受的风险级别，误报面极小且有基线棘轮兜底） |
| B | 只放宽字符类把 `[`/`]` 加进普通段 | 改动最小 | `[`/`]` 成为普通字符后 `[[...slug]]`/markdown 链接文本歧义大；失去「段=完整括号对」结构（划分不唯一风险回潮） |
| C | 不改正则，文档约定继续 `...` 模糊逃逸 | 零改动 | 精确引用永远写不了，方括号路径引用零校验——用户实证缺口原样保留 |

覆盖决策：D-006@v1 约束沿用（展开循环形不变，仅迭代体内并列第三种段形态）。

### 问题②（陈旧基线自动重锚）

| 方案 | 核心思路 | 优势 | 劣势 |
| --- | --- | --- | --- |
| A（选定） | 陈旧分支（已实测 current ≤ originCount）自动 `writeBaseline(current)` + 消息披露「已自动重锚 404→410」；仅缺省配置口径触发（`--paths` 覆盖时不写，防子集计数污染基线） | 已验证事实落盘（gate 已实付远端实测成本）；提示出现一次即消失；后续 gate 回快路径零远端成本；非「悄悄」——消息明示重锚前后值 | gate 从纯读变有条件写（写面仅基线文件一个，且写的是已验证不劣于远端的值；首次立线仍须显式 `--init-baseline` 不变） |
| B | 只改提示文案：写明触发条件「何时该跑 --init-baseline」 | 写面零变化 | 用户字面建议但治标——提示照旧每次出现、远端实测照旧每次重付，痛点不消 |
| C | local.yaml 配置键开启自动重锚（缺省关） | 显式 opt-in 无争议 | 配置面 +1；缺省不解决用户实证痛点；与「已验证即落盘」的机械语义相比多余 |

「不悄悄合法化存量」红线核对：该原则约束的是**首次立线**（无基线时不得自动生成，防存量整体合法化）——自动重锚仅在基线已存在、且本次已实测「不劣于远端」的分支触发，落盘值 ≤ 远端实测值，棘轮只紧不松；首次立线路径（exit 2 提示显式 init）不变。

## 推荐与依据

两问题均选 A：①用户原始反馈即方向（「值得工具侧补方括号支持」=语法扩展非文档约定）；②用户痛点是「从不自动重锚」而非「说明不够」（字面建议的触发条件说明被自动重锚的披露消息包含——已重锚即无需再解释何时手动重锚），且 D-001（docs-fix-capability）留账的「gate 增强等第二次批量事件」由本用户实证触发。本会话自主推进不再停等。
