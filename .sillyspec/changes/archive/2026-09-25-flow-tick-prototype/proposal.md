- fresh 与 adopt 简报加任务勾选纪律：干活时逐条勾选 tasks.md 的 - [ ] task-NN → [x]（勾选=收口哨兵证据面；全勾无证据会被拒收）
- adopt 简报动态枚举变更目录实际产物（design.md/decisions.md/proposal.md/requirements.md/prototypes/*.html/*.md）为必读列表——原型显式点名必看必用
- flow status 显示 tasks.md 勾选进度（checked/total）
- flow done 收口 advisory：有 tasks 且全未勾但有交付提交时提醒（不阻断——不勾选是记账缺失非假勾）
- 测试：简报勾选纪律断言/adopt 产物列举断言/status 勾选显示/收口 advisory 三面
