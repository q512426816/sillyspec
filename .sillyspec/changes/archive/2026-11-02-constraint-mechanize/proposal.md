# 提案书（Proposal）— 2026-11-02-constraint-mechanize

任务原话转写：约束力机制化：规约 00 反例与事故转写字段

- FR-03 模板更新：AGENTS.md 的规约 00 或知识库 conventions 加任务词汇反例注记（持久载体）
