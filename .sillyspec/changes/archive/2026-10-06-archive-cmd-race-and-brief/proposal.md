# 提案书（Proposal）— 2026-10-06-archive-cmd-race-and-brief

## 动机

任务原话转写：轻量变更全流程实测（2026-10-06-flow-status-json）发现两处工具缺陷：① flow done 归档收尾打印的「一笔到位 commit 命令」照抄执行报 pathspec did not match——多 agent 共享仓下，建议生成与执行之间暂存区可被兄弟会话/后台同步瞬改，生成器把转瞬即逝的 A 条目源侧路径抄进 pathspec，且 dst 侧逐文件罗列放大竞态面（镜像单会话复盘命令干净，真仓竞态必现一次）；② flow done 首轮中断简报「待办」把本轮刚完成的子步也列出（st 为运行开始时旧态，mark() 只写盘不回填内存）——重入后显示才正确，首轮误导。修复：① pathspec 构成改为 src 侧锚定不可变 HEAD 树 + dst 侧收拢为本变更专属归档目录 pathspec + 残余竞态给 fallback 提示；② 待办计算并入本轮 doneList。

成功标准：
- 归档建议命令的 src 侧 pathspec 仅含 HEAD 树在册路径（转瞬即逝的源侧 A 条目不进命令）；dst 侧为单条归档目录 pathspec；正常形态下打印命令可原样执行成功（exit 0）
- 竞态注入形态（源侧幽灵 A 条目进暂存区后消失）下，打印命令仍可执行成功且提交面不含幽灵路径
- flow done 首轮中断简报的「待办」不再包含本轮已完成/已跳过的子步（与重入后口径一致）
- 新增单元测试覆盖上述三点并纳入 test:core，test:core 全绿
