# 提案书（Proposal）— 2026-10-19-thin-review-material-pack

## 动机

任务原话转写：轻量评审任务书预消化材料包

动机与背景：轻量变更独立评审慢——任务书把原始件（requirements/design/change.patch）原样丢给零上下文评审员，定位类通读与大 patch prefill 是主要成本（冻结件实测最大 365KB）。完整流程五阶段已有材料包先例（review-material-pack.js，2026-09-19 成本复盘 ~200x 信息放大），轻量道评审（flow-review.js）未接同款机制。本变更为轻量评审任务书注入机械预消化材料包：FR 绑定表 + 冻结 patch 文件级 stat/hunk 图，砍定位类请求。

成功标准：
- flow done 渲染的评审任务书在材料可得时含预消化段：FR↔测试绑定表（从 requirements.md 机械解析）与冻结 patch 文件级摘要（从 change.patch 本身解析，不走活 git）
- 材料包纯机械抽取（CLI 确定性解析，无模型生成内容），带体积帽（对齐 12000 字符先例）
- 材料缺件/空变更面时零注入，任务书与现状逐字一致（零回归）
- 新增测试覆盖零注入一致/注入形态/帽截断三态并全绿
