# 提案书（Proposal）— 2026-11-04-fence-aware-task-rows

## 动机

任务原话转写：任务行解析围栏感知守卫防幻影任务
tasks.md 内代码围栏中的示例任务行（如文档示例 - [ ] task-99:）会被 task-tick 逐行正则计为真实任务，污染进度 N/M 与下一任务指针，甚至被全文正则误翻格（superpowers #2436 同型实证：未闭合围栏把 177 行任务吞成 1159 行简报）。

成功标准：
- 围栏内 task-N: 行不计入任务集（tick/进度/下一任务指针均不受影响），真实行翻格字节级不受损（含 CRLF 保留）
- 未闭合围栏给出告警且 fail-safe（开栏后不计行），不崩溃不误报
- 新增单测覆盖上述边界，既有回归面全绿

## 变更范围
